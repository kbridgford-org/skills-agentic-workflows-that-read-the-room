## Recent GitHub Blog and Changelog highlights

- **Copilot code review can now approve pull requests** (Sep 1, 2026, Changelog) — Copilot's review agent can approve PRs, not just leave comments, speeding up routine reviews.
- **Refreshed repository pull requests page in public preview** (Sep 10, 2026, Changelog) — a redesigned PR list view for repositories is rolling out in public preview.
- **Control GitHub Actions cache access with cache-mode** (Sep 10, 2026, Changelog) — a new `cache-mode` setting restricts who can read or write Actions caches, closing a supply-chain risk.
- **Block pull requests with exposed secrets from merging** (Sep 9, 2026, Changelog) — merges are now blocked when a PR contains a detected secret, adding a safety net before code ships.
- **Configure cost and quality in Copilot auto model selection** (Sep 14, 2026, Changelog) — teams can tune how Copilot balances cost versus quality when it auto-selects a model.
- **How canvases make agentic workflows visible, steerable, and cost-efficient** (Aug 17, 2026, GitHub Blog) — a look at using visual canvases instead of chat to keep Copilot agent work transparent and controllable.
