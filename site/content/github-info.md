## Recent GitHub Blog and Changelog highlights

- **Copilot app for beginners** — New walkthroughs cover viewing diffs, using the terminal, and running several Copilot agents at once inside the Copilot app, making it easier for newcomers to get hands-on. (Source: github.blog)
- **Refreshed repository pull requests page** — A redesigned repo-level PR list is in public preview with better filtering and a more compact view, helping teams triage pull requests faster. (Source: github.blog/changelog)
- **Copilot code review auto-resolution** — Copilot code review now auto-resolves its own comments once they're addressed and writes smart commit messages for applied suggestions, streamlining the review loop. (Source: github.blog/changelog)
- **Actions cache access control** — A new `cache-mode` option lets workflows enforce least-privilege access to the GitHub Actions cache at the job level, tightening supply-chain security. (Source: github.blog/changelog)
- **AI Scan APIs for pull requests** — New REST endpoints let teams programmatically manage code scanning's AI Scan feature directly on pull requests. (Source: github.blog/changelog)
