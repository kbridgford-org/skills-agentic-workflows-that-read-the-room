## Recent GitHub Blog and Changelog stories worth watching

From the [GitHub Blog](https://github.blog/latest/):

- **"When chat is the wrong UI"** — GitHub introduces "canvases" in the Copilot app, an alternative to chat for building custom, live interfaces from plain-English descriptions.
- **AI-powered fuzzing with the GitHub Security Lab Taskflow Agent** — a new agent that automates fuzz-testing setup to help find vulnerabilities faster.
- **Rendering huge pull requests in the GitHub Copilot app** — a rebuilt diff surface designed to handle million-line pull requests smoothly.
- **Migrating the GitHub Copilot runtime to Rust, using Copilot** — an 800,000-line Rust rewrite completed with Copilot's own assistance.

From the [GitHub Changelog](https://github.blog/changelog/):

- **Agentic autofix now uses Copilot Memory** — Copilot Autofix for code scanning alerts now draws on Copilot Memory for better-informed fixes.
- **More ways to request and configure Copilot code reviews** — expanded options for triggering and customizing Copilot's automated PR reviews.
- **Require proof of presence for high-impact actions** — a new security control for sensitive account and organization actions.
- **Private saved views and "Relates to" issue relationships are now generally available** — improvements to Projects & Issues for organizing and linking work.
