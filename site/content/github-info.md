## Recent GitHub Blog and Changelog stories

- **Refreshed repository pull requests page is generally available** — the new pull requests page adds better filtering and search so you can find and act on the right pull requests faster. (Source: github.blog/changelog)
- **More ways to request and configure Copilot code reviews** — every Copilot plan, including Business and Enterprise, now gets a dedicated "code review" settings page with separate controls for draft pull requests and new commits. (Source: github.blog/changelog)
- **Workflow execution protections in GitHub Actions are now generally available** — define an allowlist of actors and events that can trigger a workflow, giving repositories and organizations tighter control over who can kick off Actions runs. (Source: github.blog/changelog)
- **Node 20 is no longer available on GitHub Actions runners** — JavaScript actions must set `runs.using` to `node24`; the temporary opt-out for older Node versions has been removed, so update and republish any actions still on Node 20. (Source: github.blog/changelog)
- **How canvases make agentic workflows visible, steerable, and cost-efficient** — a practical look at using canvases alongside chat to keep long-running Copilot agent work easy to track and steer. (Source: github.blog)
