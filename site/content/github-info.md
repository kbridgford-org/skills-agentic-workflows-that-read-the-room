- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent GitHub Blog & Changelog highlights

- Copilot code review now shows how a review evolves over time and writes commit messages on accept. (Source: github.blog/changelog)
- Workflow execution protections in GitHub Actions (allowlist controls for what workflows can run) are now generally available. (Source: github.blog/changelog)
- The Ubuntu 26.04 GitHub Actions runner image is now generally available for x64 and arm64 workflows. (Source: github.blog/changelog)
- Some GitHub Copilot models are being deprecated in mid-October across Chat, inline edits, agent modes, and completions—worth checking your setup. (Source: github.blog/changelog)
- GitHub used Copilot agents to help rewrite its own 800,000-line Copilot runtime in Rust, a real-world look at large-scale agentic coding. (Source: github.blog)
