## Recent GitHub Blog and Changelog highlights

- Copilot code review now auto-resolves its own comments once a fix is applied and writes smart commit messages for suggestions, cutting down manual PR cleanup. (github.blog/changelog)
- Copilot CLI gains multi-model orchestration ("Project HydraFusion") to match top-tier response quality at a lower estimated cost. (github.blog)
- A refreshed repository pull requests page is in public preview, with better filtering and a compact list view. (github.blog/changelog)
- GitHub Actions adds a `cache-mode` setting so workflows and jobs can enforce least-privilege access to the Actions cache. (github.blog/changelog)
- The Copilot app now supports running several agents at once and reviewing agent-generated changes via diff view, terminal, and browser. (github.blog)
